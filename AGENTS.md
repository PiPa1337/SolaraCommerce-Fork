# Flujo de entrega del repositorio

Cuando un plan de implementación solicitado por el usuario quede completamente
implementado y verificado:

1. Ejecutar las comprobaciones proporcionales al cambio.
2. Revisar que el diff no incluya secretos, dependencias, builds ni archivos de
   ejecución local.
3. Crear un commit breve y descriptivo en español.
4. Enviar el commit a `origin/main`.

No crear ni enviar commits por conversaciones de planificación, respuestas,
trabajo incompleto o verificaciones fallidas. Respetar cualquier instrucción del
usuario que pida no publicar un cambio concreto.
