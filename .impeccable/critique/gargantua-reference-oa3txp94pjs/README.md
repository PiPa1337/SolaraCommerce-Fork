# Gargantua — referencia temporal

Fuente: https://www.youtube.com/watch?v=OA3Txp94pjs

Se extrajeron los primeros 6 segundos a 10 frames por segundo (61 imágenes, incluyendo 0.0 s y 6.0 s) desde el stream visual 1080p SDR. Esta carpeta es una referencia de diseño para comparar el campo gravitacional, la lente, el disco, el bloom y las estrellas del dashboard; no es un asset del runtime.

Abrir [index.html](index.html) para recorrer la secuencia en una grilla.

Las capturas `dashboard-intro-0_5s.jpg` y `dashboard-background-ui-0.jpg`
documentan la app con la interfaz en 0%: entrada cinematográfica y estado
estable, respectivamente.
